# Agent instructions for the story reset

Start with [the Claude and Codex handoff](docs/next-session.md). The [quality guide](AGENT.md) sets expectations for the next playable scene.

- Nathanial Henniges originated the game and its core story. Ask him what to carry forward from the [previous decisions](docs/decisions.md) before drafting a new premise.
- Keep the engineer as the sole playable viewpoint. WOLF acts on his own, and essential progress needs an engineer-only path.
- Keep plot drafts in Notion. Fetch connected pages before editing and verify the saved changes. Keep spoilers out of the public website, opening scene and unrelated build output.
- Use typed GDScript, built-in Godot nodes and InputMap when the next scene needs input. Keep authored events deterministic and version saves when gameplay needs them.
- Work on one playable scene at a time. Give the engineer an action, show what WOLF chooses and show what changes. Nathanial handles any hands-on play with a separate test save. Agents use headless checks and container renders.
- Keep the asset register and credits accurate. Code and public docs use GPL-3.0-or-later. Record separate rights for art and audio before shipping either.
