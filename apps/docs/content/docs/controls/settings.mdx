---
title: Settings
description: Display, audio, controls, and saved preferences in the source game.
---

Open **Settings** from the title screen or Pause. The terminal theme belongs to this menu. Preferences persist between launches.

## Display

| Setting | What it does |
| --- | --- |
| FPS limit | 30, 60, 90, 120, 144, or uncapped |
| V-sync | Synchronizes frame delivery with the display when supported |
| Edge smoothing | Off, 2×, 4×, or 8× MSAA for 2D edges |
| Window size | Desktop: 960×540, 1280×720, or 1920×1080 |
| Fullscreen | Desktop fullscreen; the OS manages mobile window sizing |

The menu shows the detected GPU and Compatibility renderer. It does not switch renderers or guarantee that a device reaches the selected FPS limit.

## Audio

Master, Music, Effects, and Voice each have a volume slider. Preferences save, but the current source build has no music, effect tracks, or recorded voice. A silent build is expected.

## Controls

Select a keyboard or controller binding, then press the replacement input. Conflicting bindings are rejected. **Esc** or **CANCEL REBIND** cancels capture. **RESTORE DEFAULT CONTROLS** restores the original mappings.

Stick deadzone sets how far the controller stick must move before movement registers. Increase it if a stick drifts while untouched. Scroll the Controls panel to see its remaining options.

See the [default input guide](/docs/controls/input/) or [troubleshooting](/docs/controls/troubleshooting/) if a control behaves unexpectedly.
