Open **Settings** from the title screen or Pause. Preferences persist between launches in `settings.cfg` beside the [checkpoint file](/docs/controls/saves/#where-saves-live). A damaged or unexpected settings file is ignored and the defaults load instead.

## Display

| Setting | What it does |
| --- | --- |
| FPS limit | 30, 60, 90, 120, 144, or uncapped |
| V-sync | Synchronizes frame delivery with the display when supported |
| Edge smoothing | Off, 2×, 4×, or 8× MSAA for 2D edges |
| Reduced motion | Turns off camera shake and hit-stop, shortens screen flashes, shows a knocked-down engineer lying on the floor at once instead of collapsing (the thud, red wash and fade remain) and holds the Service Junction's charged door seam steady instead of strobing, makes the ceiling lamps' flicker a single, gentler dip, holds the corridor's flashing red beacons lit and steady, and keeps the mascot on the starting logo from hopping and its loading bar from sweeping; sounds and rumble stay |
| Window size | Desktop: 960×540, 1280×720, or 1920×1080. Opens at 1280×720 unless your settings file already stores a window size. Changing the FPS limit, window size or fullscreen stores the size shown, so a settings file from a build before October 10, 2026 may keep 960×540; choose 1280×720 here for the larger window |
| Fullscreen | Desktop fullscreen; the OS manages mobile window sizing. A saved window size and fullscreen apply as the game starts, on the logo screen |

The menu shows the detected GPU and the Compatibility renderer. It does not switch renderers or guarantee that a device reaches the selected FPS limit.

## Audio

Master, Music, Effects, and Voice each have a volume slider. Effects carries every sound effect: the short sounds the game generates itself (the containment gate, the relay contact, the seal landing, the chirp when a station takes a save or a copy, WOLF's joints when he answers, the soft click as a crank starts to turn, the Records exit, and the Service Junction's pump, fuse tick, blasts, sentry, winch, tank and exit bolt) and a few processed recordings (the steam of the corridor's **MANUAL BYPASS** and the Service Junction, and two of WOLF's growls; see [sound recordings](/docs/credits/#sound-recordings)). Master and Effects are the only controls over those sounds: no display or motion setting mutes them. Music and Voice have no content yet, so those sliders change nothing for now.

## Controls

These six actions have keyboard and controller bindings you can change. Rebinding replaces that action's keyboard defaults (or its controller defaults) with the one input you press:

| Action | Keyboard default | Controller default |
| --- | --- | --- |
| Move left | A or ← | D-pad left or left stick |
| Move right | D or → | D-pad right or left stick |
| Interact / continue | E | A |
| Response 1 | 1 | X |
| Response 2 | 2 | Y |
| Pause | Esc | Start |

Select a binding, then press the replacement key, button, or stick direction. A binding already used by another action is rejected. **Esc** or **CANCEL REBIND** cancels the capture, and **RESTORE DEFAULT CONTROLS** brings back the mappings above. The **I** key that cycles the provisional engineer name, the controller **B** button for backing out of menus, and the Android Back gesture are fixed.

Stick deadzone sets how far the controller stick must move before movement registers (0.1 to 0.8, default 0.25). Increase it if a stick drifts while untouched. Scroll the Controls panel to see its remaining options.

**TOGGLE HOLDS** (off by default) changes how the cranks work: the corridor's **MANUAL BYPASS** and the Service Junction's valve. With it on, one press of interact starts the crank and it keeps turning on its own; press interact again, walk away or pause to stop it, and it stops by itself once the crank is done. It works the same with the keyboard, a controller and the touch **CRANK** button, because all three press the one interact action, and while it is on the prompts drop the word **HOLD** (for example **E: crank the valve**). It is saved in `settings.cfg` with your other preferences and stays as it is when you use **RESTORE DEFAULT CONTROLS**.

See [Input](/docs/controls/input/) for the full default table or [Troubleshooting](/docs/controls/troubleshooting/) if a control behaves unexpectedly.
