title: Settings
description: Display, audio, controls, and saved preferences in the source game.
---

Open **Settings** from the title screen or Pause. Preferences persist between launches in `settings.cfg` beside the [checkpoint file](/docs/controls/saves/#where-saves-live). A damaged or unexpected settings file is ignored and the defaults load instead.

## Display

| Setting | What it does |
| --- | --- |
| FPS limit | 30, 60, 90, 120, 144, or uncapped |
| V-sync | Synchronizes frame delivery with the display when supported |
| Edge smoothing | Off, 2×, 4×, or 8× MSAA for 2D edges |
| Reduced motion | Turns off camera shake and hit-stop, shortens screen flashes, skips the engineer's fall when knocked down (the thud, red wash and fade remain) and holds the Service Junction's charged door seam steady instead of strobing; sounds and rumble stay |
| Window size | Desktop: 960×540, 1280×720, or 1920×1080 |
| Fullscreen | Desktop fullscreen; the OS manages mobile window sizing |

The menu shows the detected GPU and the Compatibility renderer. It does not switch renderers or guarantee that a device reaches the selected FPS limit.

## Audio

Master, Music, Effects, and Voice each have a volume slider. Effects carries the short sounds the game generates itself (the containment gate, the relay contact, the seal landing, the Records exit, and the Service Junction's line, blasts, sentry, winch, tank and exit bolt); there are no audio files in the source build. Music and Voice have no content yet, so those sliders change nothing for now.

## Controls

These six actions have keyboard and controller bindings you can change. Rebinding replaces that action's keyboard defaults (or its controller defaults) with the one input you press:

| Action | Keyboard default | Controller default |
| --- | --- | --- |
| Move left | A or ← | D-pad left or left stick |
| Move right | D or → | D-pad right or left stick |
| Interact / continue | E | A |
| Response 1 | 1 | X |
| Response 2 | 2 | Y |
| Pause | Esc | Start |

Select a binding, then press the replacement key, button, or stick direction. A binding already used by another action is rejected. **Esc** or **CANCEL REBIND** cancels the capture, and **RESTORE DEFAULT CONTROLS** brings back the mappings above. The **I** key that cycles the provisional engineer name, the controller **B** button for backing out of menus, and the Android Back gesture are fixed.

Stick deadzone sets how far the controller stick must move before movement registers (0.1 to 0.8, default 0.25). Increase it if a stick drifts while untouched. Scroll the Controls panel to see its remaining options.

See [Input](/docs/controls/input/) for the full default table or [Troubleshooting](/docs/controls/troubleshooting/) if a control behaves unexpectedly.
