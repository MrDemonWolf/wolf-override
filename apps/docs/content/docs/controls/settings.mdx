**What this page is for:** what each setting does, one line each.

- **Open Settings** from the title screen or from Pause.
- **Settings are saved** between launches in `settings.cfg`, next to the [checkpoint file](/docs/controls/saves/#where-saves-live).
- **A damaged settings file** is ignored, and the defaults load.
- **Accessibility settings** are gathered on the [Accessibility](/docs/accessibility/) page.

## Display

| Setting | What it does |
| --- | --- |
| FPS limit | 30, 60, 90, 120 or 144 FPS, or uncapped |
| V-sync | Matches frames to the display, when supported |
| Edge smoothing | Off, 2×, 4× or 8× MSAA for 2D edges |
| Reduced motion | Turns off shake and strobing; shortens flashes ([full list](/docs/accessibility/#reduced-motion)) |
| Window size | Desktop: 960×540, 1280×720 (default) or 1920×1080 |
| Fullscreen | Desktop fullscreen; phones and tablets size the window themselves |
| Text size | 100%, 125%, 150%, 175% or 200% for dialogue, hints, cards and station names |

- **The tab's heading** reads **THE DEN / LOCAL CONFIGURATION**.
- **Its note** reads **V-sync may limit the FPS cap.**
- **On phones and tablets** it starts with **Window size is OS-managed on mobile.**
- **The menu does not** show your graphics hardware, switch renderers or promise a device reaches the FPS limit.

<Details>
<Summary>Window size and fullscreen details</Summary>

- The game opens at 1280×720 unless your settings file already stores a window size.
- Changing the FPS limit, window size or fullscreen stores the size shown.
- A settings file from a build before October 10, 2026 may keep 960×540. Choose 1280×720 here for the larger window.
- A saved window size and fullscreen apply as the game starts, on the logo screen.

</Details>

<Details>
<Summary>Text size details</Summary>

- It enlarges the dialogue, the hint line, the location and name cards, the tutorial prompt, the answer buttons and the station names over the machines.
- Menus keep their size.
- It applies at once and is saved.
- From 150% (from 125% on touch builds, where the box is narrower), the speaker's name moves above the words, so each row keeps its length.
- Station names grow up to 150%. Above that they stay at 150% and break onto two rows between their words, so neighbouring names stay apart.
- On touch builds above 100%, the dialogue box stands between the arrows and **USE** instead of under them, with the speaker's name above the words.
- In the opening and the closing shot, the hint line sits below the top card.
- Where the tutorial prompt would cover a station name (the breaker's, at the larger sizes), it moves up into the top card's place as the card leaves. If no such place is free and no box is up, it goes to the bottom of the screen. It hides while a box is up.

</Details>

## Audio

| Slider | What it changes |
| --- | --- |
| Master | Every sound |
| Music | Nothing yet: there is no music |
| Effects | Every sound effect |
| Voice | Nothing yet: there is no voice acting |

- **Effects** covers the sounds the game makes itself and a few processed recordings ([sound recordings](/docs/credits/#sound-recordings)).
- **Only Master and Effects** control those sounds. No display or motion setting mutes them.

<Details>
<Summary>Every sound on the Effects slider</Summary>

- **Made by the game:** the guard lock tearing off WOLF's cage, the relay contact, the seal landing, the chirp when a station takes a save or a copy, WOLF's joints when he answers, the soft click as a crank starts, and the Records exit.
- **Made by the game in the Service Junction:** the pump, fuse tick, blasts, sentry, winch, tank and exit bolt.
- **Processed recordings:** the steam of the corridor's **MANUAL BYPASS** and the Service Junction, and two of WOLF's growls.

</Details>

## Controls

You can change six actions on keyboard and controller:

| Action | Keyboard default | Controller default |
| --- | --- | --- |
| Move left | A or ← | D-pad left or left stick |
| Move right | D or → | D-pad right or left stick |
| Interact / continue | E | A |
| Response 1 | 1 | X |
| Response 2 | 2 | Y |
| Pause | Esc | Start |

### Rebind an action

1. Select the binding.
2. Press the new key, button or stick direction.
3. To cancel, press **Esc** or **CANCEL REBIND**.

- **One input per action.** Rebinding replaces that action's keyboard (or controller) defaults with the one input you press.
- **No doubles.** An input already used by another action is rejected.
- **RESTORE DEFAULT CONTROLS** brings back the table above.
- **Key names follow your keyboard.** On Windows, macOS and Linux each key shows the label printed on it in your keyboard layout, so on a French AZERTY keyboard **Move left** reads Q, not A. The defaults are key positions, so they stay in the same place. Where your layout prints a symbol on a key, the key shows it (**&** on the AZERTY 1 key). A letter the game's fonts cannot draw yet, such as Greek or Hebrew, shows the key's QWERTY name instead.
- **Fixed inputs:** the **I** key (cycles the provisional engineer name), controller **B** (back in menus) and Android Back.

### Other control settings

| Setting | What it does |
| --- | --- |
| Stick deadzone | How far the stick must move before it counts: 0.1 to 0.8, default 0.25. Raise it if the stick drifts. |
| TOGGLE HOLDS | One press starts a crank and keeps it turning. Off by default. See [Hold to crank](/docs/controls/input/#toggle-holds). |

- **Scroll the Controls panel** to see its remaining options.

## Language

- **English and Spanish:** Español (Latinoamérica) and Español (España). Which parts are translated: [Platforms and languages](/docs/platforms/#languages).
- **Where it is:** the **GENERAL** tab, one **LANGUAGE** row.
- **Each language is named in its own words**, such as Español (Latinoamérica).
- **Until you choose one,** the game uses your system's language, or English if it has no translation for it. Spain gets Español (España); every other Spanish region gets Español (Latinoamérica).
- **Your choice is saved** in `settings.cfg`.
- **Machine translation** is marked: an unreviewed language shows a small "machine translation" line, in that language, under its name in the list and under the row.
