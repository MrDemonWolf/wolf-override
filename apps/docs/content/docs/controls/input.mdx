title: Input guide

---

You control the engineer. WOLF is an independent companion. The in-game prompts follow your selected keyboard or controller bindings.

## Keyboard and mouse

| Input | Action |
| --- | --- |
| A / D or left / right arrow | Move |
| E | Interact; advance the opening or chapter closing beat |
| 1 / 2 or click a response | Choose the displayed answer |
| Esc | Pause or resume during play; skip the opening |
| L or F9 | Restore the checkpoint |
| N | Start a clean run, including the opening |
| I | Cycle provisional engineer display names |

## Controller

| Default input | Action |
| --- | --- |
| Left stick or D-pad left / right | Move |
| A | Interact or advance |
| X / Y | Choose answer 1 / 2 |
| Start | Pause; skip the opening |

These are generic controller labels. Equivalent buttons may have different labels on your controller. Menus support focus navigation and confirmation, but a complete physical-controller playtest remains outstanding.

## Touch

On iOS and Android builds, hold the left/right arrows to move, tap **USE** to interact, and tap the displayed answer. **PAUSE** opens Resume, Settings, and Return to Title.

Touch controls appear in mobile builds. There is no public mobile download yet. A simulator launch has been checked; complete touch gestures and physical devices remain unverified.

Need to change a binding? Open [Settings](/docs/controls/settings/). For checkpoint behavior, see [Saving and resuming](/docs/controls/saves/).
