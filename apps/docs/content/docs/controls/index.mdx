You play the engineer throughout the chapter. WOLF follows and acts independently. Start with the default inputs below; the game prompts reflect any bindings you change in Settings.

| Input | Action |
| --- | --- |
| **A / D** or **← / →** | Move |
| **E** | Interact or advance dialogue |
| **1 / 2** or click a response | Choose an answer |
| **Esc** | Pause during play; skip the opening |
| **L** or **F9** | Restore the checkpoint |
