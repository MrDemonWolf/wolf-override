---
title: Saving and resuming
description: How the safe point, Continue, New Game, and Pause affect your chapter progress.
---

## Make a checkpoint

Use the green **SAFE POINT** beyond the sealed door. **Continue** on the title screen requires a valid checkpoint and restores the saved room, character positions, puzzle state, display name, and actual remembered choices.

There is one checkpoint file, not multiple save slots. Loading a missing or invalid checkpoint leaves the current run unchanged.

When **Continue** is unavailable, a short note under it says why: **No checkpoint yet** means you have not saved at a safe point, and **Saved checkpoint could not be read** means the checkpoint file is damaged. Reaching the safe point in a new run replaces a damaged file.

Entering Records Access, copying a trace there and securing the exit also save your progress. If one of those saves fails, the hint line shows **Save failed. Use the next station to try again.** Progress since the last successful save is stored once a later save works. If the first safe-point save fails, the safe point stays unused so you can use it again.

If the game closes while it is writing a save, Continue recovers the save that was being written when it is complete and valid.

## Leave or restart

- **Return to Title** keeps the last checkpoint. Progress made after it is lost.
- **New Game** begins a fresh run with the opening. The old checkpoint remains until the fresh run saves over it.
- **L** or **F9** restores the last checkpoint during play with default keyboard bindings.

## Pause

During gameplay or a player-paced closing beat, **Esc** opens Pause. Choose **Resume**, **Settings**, or **Return to Title**. During the opening, Pause shows **Skip Opening** in place of Return to Title. Switching away from the game during play also opens Pause; it does not save, so progress since the last safe point stays unsaved.

For the path to the safe point, see the optional [corridor walkthrough](/docs/walkthrough/corridor/). For other keys, see the [input guide](/docs/controls/input/).
