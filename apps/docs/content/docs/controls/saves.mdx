---
title: Saving and resuming
description: How the safe point, Continue, New Game, and Pause affect your chapter progress.
---

## Make a checkpoint

Use the green **SAFE POINT** beyond the sealed door. **Continue** on the title screen requires a valid checkpoint and restores the saved room, character positions, puzzle state, display name, and actual remembered choices.

There is one checkpoint file, not multiple save slots. Loading a missing or invalid checkpoint leaves the current run unchanged.

## Leave or restart

- **Return to Title** keeps the last checkpoint. Progress made after it is lost.
- **New Game** begins a fresh run with the opening. The old checkpoint remains until the fresh run saves over it.
- **L** or **F9** restores the last checkpoint during play with default keyboard bindings.

## Pause

During gameplay or a player-paced closing beat, **Esc** opens Pause. Choose **Resume**, **Settings**, or **Return to Title**. During the opening, that binding skips the opening instead of showing Pause.

For the path to the safe point, see the optional [corridor walkthrough](/docs/walkthrough/corridor/). For other keys, see the [input guide](/docs/controls/input/).
