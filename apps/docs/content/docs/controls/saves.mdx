title: Saving and resuming
description: How the safe point, Continue, New Game, and Pause affect your chapter progress.
---

## Make a checkpoint

Use the green **SAFE POINT** beyond the sealed door. **Continue** on the title screen requires a valid checkpoint and restores the saved room, character positions, puzzle state, display name, and actual remembered choices.

There is one checkpoint file, not multiple save slots. Loading a missing or invalid checkpoint leaves the current run unchanged.

When **Continue** is unavailable, a short note under it says why: **No checkpoint yet** means you have not saved at a safe point, and **Saved checkpoint could not be read** means the checkpoint file is damaged. Reaching the safe point in a new run replaces a damaged file.

Entering Records Access, copying a trace there and securing the exit also save your progress. If one of those saves fails, the hint line shows **Save failed. Use a station to try again.** until you move to another spot or a later save works. After the exit fails to save, it stays until a later save works. Using the same station again tries the save again; if entering Records Access did not save, the first station there does. Progress since the last successful save is stored once a later save works. If the first safe-point save fails, the safe point stays unused so you can use it again.

Entering the Service Junction, blowing its door, bringing down the sentry and leaving through the exit hatch also save. Being knocked down there (by the relief vent, the door blast, the sentry or the coolant cloud) returns you to the most recent of those saves; the knockdown itself never writes the file, and your earlier choices and Records progress are kept.

If the checkpoint file is missing or damaged but a complete save was still being written when the game closed, Continue uses that save instead.

## Leave or restart

- **Return to Title** keeps the last checkpoint. Progress made after it is lost.
- **New Game** begins a fresh run with the opening. The old checkpoint remains until the fresh run saves over it.
- To restore the last checkpoint during play, open **Pause**, choose **Return to Title** (it warns that unsaved progress is lost), then **Continue**.

## Pause

During gameplay or a player-paced closing beat, **Esc** opens Pause. Choose **Resume**, **Settings**, or **Return to Title**. During the opening, Pause shows **Skip Opening** in place of Return to Title. Switching away from the game during play also opens Pause; it does not save, so progress since the last safe point stays unsaved.
