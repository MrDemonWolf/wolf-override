---
title: Troubleshooting
description: Quick fixes for missing prompts, checkpoints, controls, sound, and source setup.
---

| Problem | Try this |
| --- | --- |
| The objective card disappeared | Check station labels and nearby interaction prompts, or open the [walkthrough](/docs/walkthrough/). |
| WOLF will not help at the relay | Advance his response and use the manual bypass. His refusal keeps an engineer-only route open. |
| Continue is disabled | Reach and use the safe point first. Continue requires a valid checkpoint file. |
| Loading says no valid checkpoint exists | The current run stays unchanged. Continue playing to the safe point. |
| Movement or choices use unexpected keys | Check [Settings](/docs/controls/settings/) or restore default bindings. |
| There is no sound | Audio content has not been added to this source build. |
| The game will not open | Verify Godot 4.7.2 and import the project through the editor; see [source setup](/docs/development/setup/). |

Report reproducible problems through [GitHub Issues](https://github.com/MrDemonWolf/wolf-override/issues). Include your OS, Godot version, input method, and steps. Omit private notes and personal paths from logs.
