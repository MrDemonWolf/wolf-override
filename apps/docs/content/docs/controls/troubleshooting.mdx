---
title: Troubleshooting
description: Quick fixes for missing prompts, checkpoints, controls, sound, and source setup.
---

| Problem | Try this |
| --- | --- |
| The objective card disappeared | It only shows briefly when your goal changes. Check station labels and the nearby prompt, or open the [walkthrough](/docs/walkthrough/). |
| WOLF will not help at the relay | Interact again to take the engineer's manual bypass. His refusal keeps an engineer-only route open. |
| Continue is disabled | Read the note under Continue. **No checkpoint yet**: reach and use the safe point first. **Saved checkpoint could not be read**: the file is damaged; start a New Game and use the safe point to replace it. |
| The hint says **Save failed** | Use a station to retry the save. See [Saving](/docs/controls/saves/). |
| I want to go back to my last checkpoint | Open Pause, choose **Return to Title** (unsaved progress is lost), then **Continue**. There are no load or restart hotkeys. |
| Movement or choices use unexpected keys | Open [Settings](/docs/controls/settings/) and check the Controls tab, or choose **RESTORE DEFAULT CONTROLS**. |
| The game closed when I pressed Back on Android | Back closes the game only from the title screen. During play it pauses; in menus it steps back one level. |
| There is no sound | Audio content has not been added to this source build. |
| The game will not open | Verify Godot 4.7.2 and import the project through the editor; see [source setup](/docs/development/setup/). |

Report reproducible problems through [GitHub Issues](https://github.com/MrDemonWolf/wolf-override/issues). Include your OS, Godot version, input method, and steps. Omit private notes and personal paths from logs.
