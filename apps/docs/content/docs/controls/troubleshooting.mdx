---
title: Troubleshooting
description: Quick fixes for missing prompts, checkpoints, controls, sound, and source setup.
---

| Problem | Try this |
| --- | --- |
| The objective card disappeared | Check station labels and nearby interaction prompts, or open the [walkthrough](/docs/walkthrough/). |
| WOLF will not help at the relay | Advance his response and use the manual bypass. His refusal keeps an engineer-only route open. |
| Continue is disabled | Read the note under Continue. **No checkpoint yet**: reach and use the safe point first. **Saved checkpoint could not be read**: the file is damaged; start a New Game and use the safe point to replace it. |
| The hint says **Save failed** | Use a station (pressing interact anywhere in Records Access or the Service Junction also works) to retry the save. See [saving and resuming](/docs/controls/saves/). |
| The screen went red and the room reset | You were knocked down. The dialogue line names the cause and the fix; play resumes from the room's last autosave with your choices intact. See the [Service Junction guide](/docs/walkthrough/service-junction/). |
| Loading says no valid checkpoint exists | The current run stays unchanged. Continue playing to the safe point. |
| Movement or choices use unexpected keys | Check [Settings](/docs/controls/settings/) or restore default bindings. |
| There is no sound | Only short generated effects exist (the gate, the relay, the seal, the exit, and the Service Junction's line, blast, sentry, tank and exit bolt); there is no music or voice yet. If those are silent, check the Master and Effects sliders in [Settings](/docs/controls/settings/). |
| The game will not open | Verify Godot 4.7.2 and import the project through the editor; see [source setup](/docs/development/setup/). |

Report reproducible problems through [GitHub Issues](https://github.com/MrDemonWolf/wolf-override/issues). Include your OS, Godot version, input method, and steps. Omit private notes and personal paths from logs.
