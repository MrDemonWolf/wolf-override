## Report a bug

1. Check [Troubleshooting](/docs/controls/troubleshooting/) and the open [issues](https://github.com/MrDemonWolf/wolf-override/issues). Someone may have reported it already.
2. Write down what you did, step by step, and what went wrong.
3. Save a bug capture with **F12** if you can (see below).
4. Open a [new GitHub issue](https://github.com/MrDemonWolf/wolf-override/issues/new). You need a GitHub account.
5. Add the details from the list below.

### What to include

- **Your system:** macOS, Windows or Linux, and its version.
- **How you run the game:** a test build (with its commit) or the source in Godot 4.7.2.
- **Your input:** keyboard, controller (which one) or touch.
- **The steps** that make the bug happen.
- **What you expected** and what happened instead.
- **A bug capture or screenshot,** if you have one.

<Callout type="warn" title="Keep personal details out">
  Logs and paths can show your user name. Remove personal details before you post. Keep private story notes out of public issues.
</Callout>

## Spotted a translation mistake?

Every language except English is a machine translation that no native speaker has reviewed yet. Reports help fix them.

1. Open the [translation issue form](https://github.com/MrDemonWolf/wolf-override/issues/new?template=translation.yml). You need a GitHub account.
2. Pick the language.
3. Say where in the game you saw it: the screen or room.
4. Copy the text as shown, and write what it should say.
5. Add a screenshot if you can.

- **No GitHub account?** Post it on the [Discord server](https://discord.com/invite/A9x3qEN) instead.
- **Which languages exist:** [Platforms and languages](/docs/platforms/#languages).

## Save a bug capture (F12)

A **bug capture** is a screenshot plus a data file that records what the game was doing.

1. Make sure the debug tools are on. They are always on in [test builds](/docs/test-builds/) and source runs.
2. When the bug is on screen, press **F12**.
3. The game shows where it saved the capture.
4. Open that folder and attach both files to your issue.

- **Where:** the `debug-captures` folder inside the save folder. See [Saving and retrying](/docs/controls/saves/#where-saves-live) for the path.
- **What is in it:** see [Privacy](/docs/privacy/#bug-captures). It never leaves your computer unless you share it.
- **On a phone or without F12:** open the debug menu and choose **VIEW → BUG CAPTURE**.
- **More detail:** [Debug tools](/docs/development/debug-tools/).

## Report a security problem

<Callout type="warn" title="Not in a public issue">
  Do not post a security problem in a public issue or pull request.
</Callout>

1. Read [SECURITY.md](https://github.com/MrDemonWolf/wolf-override/blob/main/SECURITY.md).
2. Contact Nathanial Henniges privately, as it describes.
3. Say in your first line that it is a security report.
