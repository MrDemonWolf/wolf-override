**What this page is for:** what runs where today, and in which languages.

- **No release yet.** No platform has an installer, a store page or a release date.
- **Two ways to play today:** the source game in Godot, or a test build. See [Get the game](/docs/get-game/).

## Platforms

| Platform | Source game in Godot | Test build | Release |
| --- | --- | --- | --- |
| Windows (64-bit) | Yes | Yes | Planned, no date |
| macOS | Yes | Yes | Planned, no date |
| Linux | Yes | No | Not announced |
| iPhone and iPad | No | No | Planned, no date |
| Android | No | No | Planned, no date |

- **Source game:** you run the project in Godot 4.7.2, the free game engine. Steps: [Get the game](/docs/get-game/).
- **Test build:** an unsigned debug build made from each change, no Godot needed. Steps: [Install a test build](/docs/test-builds/).
- **Planned** means a target, not a promise. It does not mean a store listing exists.
- **Phones and tablets:** the game has a touch layout, but there is no phone or tablet build to install.

<Callout title="What has been tried on real systems">
  No build has been played by hand on any of these systems as a check. Test builds are checked for their contents only. See [What was checked](/docs/development/evidence/).
</Callout>

## Languages

| Language | Status |
| --- | --- |
| English | In the game |
| Deutsch | In the game: machine translation, review pending |
| Español (Latinoamérica) | In the game: machine translation, review pending |
| Español (España) | In the game: machine translation, review pending |
| Français | In the game: machine translation, review pending |
| Português (Brasil) | In the game: machine translation, review pending |
| Other languages | Planned, no date |

- **Each translation covers the menus, the HUD and the story:** the title, Pause, Settings, the credits, the hints, objectives, cards, tutorial and touch buttons, the dialogue, narration and end card, and a few station names.
- **Still in English:** most station names, and the in-game changelog.
- **Portugal** gets Português (Brasil), the one Portuguese file.
- **Machine translation:** no native speaker has reviewed any of them yet, and the game says so under each name. Who made it: [Credits](/docs/credits/#translations).
- **Choose a language** in Settings. Steps: [Settings](/docs/controls/settings/#language).
- **The website** is in English only.
