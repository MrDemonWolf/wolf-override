**Puzzle solutions for the second source room follow.** The [maintenance corridor](/docs/walkthrough/corridor/) comes first.

WOLF heads toward the mirror independently while you keep control of the engineer.

## 1. Copy the purge trace

Interact with the **PURGE QUEUE** on the left to copy its trace.

## 2. Preserve a timestamp

Interact with the **MIRROR PORT** in the middle. Choose **1** when WOLF is ready to use his readout, or **2** for the manual maintenance port. If he is still checking, wait or use the manual option.

## 3. Open the exit

Move to the **EXIT** on the right and interact. The shutter opens when the first copy is secured. Advance the closing beat to return to control.

The preserved traces are a first lead. A full investigation is still future work. Continue restores saved chapter progress.

## After the slice

You can revisit the room, return to the title through Pause, or start another run to try the other response. **New Game** clears the current timeline; it retains the previous checkpoint until the new run saves over it.

If you are stuck, [troubleshooting](/docs/controls/troubleshooting/) has recovery tips. [Testing and deployment](/docs/development/testing/) explains which routes have automated checks and which still need hands-on play.
