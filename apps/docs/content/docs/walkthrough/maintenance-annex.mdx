**What this page is for:** how to use the annex's three stations and finish the current chapter.

## Enter the annex

1. Leave the [Service Junction](/docs/walkthrough/service-junction/) through its open exit.
2. Read the **MAINTENANCE ANNEX** location card and objective.
3. Approach the **TRANSFER FRAGMENT** station.

- This room reuses existing Records Access artwork as provisional staging.
- It represents record access, not a newly painted or operating freight lift.
- You control the engineer throughout; WOLF's participation is not required.

## Check the three stations

1. Use **TRANSFER FRAGMENT** and read the response.
2. Use **LIFT READOUT** to make the next comparison.
3. Use **ESCORT FILE** at the cabinet for the final crosscheck.
4. Advance the closing dialogue at your own pace.

- Read the nearby prompt to see which station is needed next.
- Progress saves on entry and after each completed station.
- Continue after the last record lets you read the closing discovery again.
- These are separate checks; copying one source twice does not add another source.

## Finish Chapter 1

1. Finish reading the closing dialogue.
2. Approach the exit and press interact.
3. Read the **CHAPTER 1 COMPLETE** recap card.
4. Press Continue to return to the title; **PLAY AGAIN** begins a fresh run.

- The next story goal is shown in the game; later chapters remain in development.
- The finished save stays until a new run saves over it.
- [Saving and retrying](/docs/controls/saves/) explains Continue and checkpoint files.
