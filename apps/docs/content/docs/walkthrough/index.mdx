**Puzzle solutions ahead.** This guide covers the current three-room source chapter only. It does not reveal future chapters or campaign endings.

## The route

**Maintenance corridor:** Breaker → Coolant relay → Safe point. [Open the corridor guide](/docs/walkthrough/corridor/).

**Records Access:** Purge queue → Mirror port → Exit. [Open the Records Access guide](/docs/walkthrough/records-access/).

**Service Junction (in progress):** Overload breaker → Valve → Clear the door. [Open the Service Junction guide](/docs/walkthrough/service-junction/).

You always control the engineer. WOLF can help, refuse, or use his own readout; essential progress has a manual path. Choices affect his responses but do not block the chapter.

For default keys and recovery tips, see [Controls and settings](/docs/controls/). For a spoiler-light introduction, return to [Start here](/docs/).
