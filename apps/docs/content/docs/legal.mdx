## Code and documentation

The game code and public documentation in this repository are available under [GNU GPL version 3 or later](https://github.com/MrDemonWolf/wolf-override/blob/main/LICENSE). The license file in the repository is the controlling text for those materials.

## Artwork and other assets

Artwork and other media have separate rights from the code and documentation. The current game's provisional art was generated with AI image tools and then reviewed by a person before use: the WOLF, engineer and Director sprites and the title image with ChatGPT Create, and the layered room plates, station props, redrawn sprites and the sentry with the Codex image generation tool, each set reviewed and approved by Nathanial Henniges for this prototype. The WOLF//OVERRIDE mark started as a ChatGPT Create concept and was redrawn by the project as original SVG paths; its trademark and rights review is still pending. The final commercial rights review for all of this art remains open, and the GPL notice does **not** grant a license to reuse it. Check the [asset register](https://github.com/MrDemonWolf/wolf-override/blob/main/apps/game/assets/manifest.json) for each asset's source, review and status.

Not everything in the game is AI-generated. The sound effects are produced by the game's own code from fixed recipes, and the shaders, UI theme and font settings are project-written resources; they are covered by the code licence. The fonts are third-party work under their own licence (below). The game code and the public documentation were written with AI assistance (ChatGPT, Codex and Claude Code) under Nathanial's direction and human review; no AI service runs inside the game or the website.

The original game concept, core story, and creative vision are by Nathanial Henniges. Consulted research sources and software tools are credited separately; they are not project contributors or endorsers unless explicitly stated.

## Website privacy

The project site has no account, newsletter, contact form, or custom analytics integration, and it does not read your browser's platform information: the landing page lists every planned platform in plain text. The game guide stores only your light or dark theme choice in your browser's local storage, and only after you use the theme switch. GitHub Pages hosts the site; request handling is subject to [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). External links are governed by their providers' terms and privacy practices. The [Privacy](/docs/privacy/) page covers the website and the game's save and settings files in full.
