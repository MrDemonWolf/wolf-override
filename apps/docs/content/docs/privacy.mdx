WOLF//OVERRIDE has no account, sign-in, online service or telemetry. This page says in plain terms what the source game and this website keep on your device and what leaves it. It describes the current source build and was checked against the code on October 10, 2026; it is a description, not legal advice.

## The game

### What it stores

The game writes two files to Godot's user data folder for the project and nothing else:

| File | Contents |
| --- | --- |
| `m0-save.json` | The checkpoint: the current room, the engineer's and WOLF's positions, puzzle state, which of the three preset engineer names is in use, and the reply WOLF remembers from the corridor choice. There is one checkpoint and each save replaces it; a save is written to `m0-save.json.tmp` first and renamed when complete. |
| `settings.cfg` | Your settings: FPS limit, window size, fullscreen, V-sync, MSAA, Reduced Motion, the audio slider levels, the controller deadzone and your key bindings. |

The game has no text entry. The engineer's display name is cycled from a fixed list, so nothing you type is stored. The game does not read your account name, hardware identifiers, location or clipboard.

### Where it lives and how to delete it

[Saving](/docs/controls/saves/) lists the folder for macOS, Windows and Linux (`Godot/app_userdata/WOLF--OVERRIDE/` under the platform's application data directory). Deleting the two files, or the whole folder, removes your checkpoint and settings: Continue then reads **No checkpoint yet** and the settings return to their defaults. `bun run game:check` uses a temporary folder and never touches these files.

### What it sends

Nothing. The game makes no network requests: no crash reports, update checks, analytics or accounts. The only outward action is the **Changelog** screen's online button, which asks your operating system to open [the changelog on this website](/docs/changelog/) in your browser; the changelog text shown inside the game is bundled with it. The Credits screen is shown in the game and opens nothing. Once you are in the browser, the website section below applies.

The Godot editor you use to run the source has its own settings and behaviour, documented by the Godot project; they are not part of this game.

## This website

### What it stores

The game guide's light or dark switch saves your choice in your browser's local storage under the key `theme`, and only once you use the switch; the site starts dark. The landing page stores nothing. The site sets no cookies and has no account, contact form, newsletter, search or comments.

To remove the stored choice, clear the site data for `wolfoverride.mrdemonwolf.dev` in your browser.

### What it loads

The built site loads no analytics, tracking pixels, third-party scripts, stylesheets or fonts. Roboto and Montserrat are served from the site itself, and the pages and images come from the same address. The export is checked on every build.

### Who sees your visit

GitHub Pages hosts the site, so GitHub receives the normal web request for each page (your IP address, browser details and the page you asked for) under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The project runs no server of its own and receives no visitor logs.

Links to GitHub, the Godot downloads, the Discord server and the research references leave this site; those providers' own terms and privacy practices apply.
