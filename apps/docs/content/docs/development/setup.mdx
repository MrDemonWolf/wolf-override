**Status:** there is no packaged game download or installer yet; the playable chapter slice runs from this repository in Godot 4.7.2. Bun is needed only for website work.

## Play on Windows, macOS, or Linux

1. Install the standard editor build of [Godot 4.7.2](https://godotengine.org/download/archive/) for your operating system.
2. Download the [current source ZIP](https://github.com/MrDemonWolf/wolf-override/archive/refs/heads/main.zip) and extract it, or clone the repository:

   ```sh
   git clone https://github.com/MrDemonWolf/wolf-override.git
   cd wolf-override
   ```

3. Open Godot Project Manager, choose **Import**, and select `apps/game/project.godot` inside the extracted folder. Open the imported project and press **F5** to run the game.

If you have Git and Godot on your command line, you can import and launch from the repository root:

   ```sh
   godot --path apps/game --editor
   ```

After importing, `godot --path apps/game` launches the game directly.

[Start here](/docs/) introduces the first goal. [Play and settings](/docs/controls/) covers input and checkpoints. The [chapter walkthrough](/docs/walkthrough/) contains optional puzzle solutions.

## Run the docs site

The repository pins Bun 1.4.2. From the repository root, check `bun --version`, then run:

```sh
bun install --frozen-lockfile
bun run docs:dev
```

Open the local URL printed by Next.js. Bun is not needed to play the game.

For automated commands and validation limits, see [Testing and deployment](/docs/development/testing/).
