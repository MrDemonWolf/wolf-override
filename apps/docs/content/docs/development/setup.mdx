**Status:** there is no packaged game release or installer yet; the playable chapter slice runs from this repository in Godot 4.7.2, and unsigned debug [test builds](/docs/test-builds/) for macOS and Windows are made from each change. Bun is needed only for website work.

## Play the game

- **Steps:** [Get the game](/docs/get-game/#run-the-source-game) is the one home for the install and run steps, including the command-line way.
- **Then:** [Start here](/docs/) introduces the first goal, [Play overview](/docs/controls/) covers input and checkpoints, and the [chapter walkthrough](/docs/walkthrough/) has optional puzzle solutions.

## Run the docs site

The repository pins Bun 1.4.2. From the repository root, check `bun --version`, then run:

```sh
bun install --frozen-lockfile
bun run docs:dev
```

Open the local URL printed by Next.js. Bun is not needed to play the game.

For automated commands and validation limits, see [Testing and deployment](/docs/development/testing/).
