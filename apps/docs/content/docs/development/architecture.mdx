## The game

```text
apps/game/
  project.godot        settings, the version, the input map
  export_presets.cfg   macOS and Windows test build presets
  scenes/              studio_logo.tscn (first scene), main.tscn (the game)
  scripts/             game code (below)
  tests/               headless suites, one *_test.gd each
  assets/              art, sound, fonts, shaders, the asset register
  i18n/                the language table
```

- **Start-up:** `studio_logo.tscn` plays the MrDemonWolf, Inc. logo, then hands over to `main.tscn`.
- **Typed GDScript** with Godot's built-in nodes and input map.

### Scripts by job

| Job | Scripts |
| --- | --- |
| The game loop | `main.gd` (`Main`): rooms, dialogue, choices, saves, the title and menus |
| Story state | `m0_state.gd` (pure logic), `m0_actor.gd` (the engineer's and WOLF's bodies) |
| Rooms | `room_depth.gd` (painted plates and room light), `records_room.gd`, `junction_room.gd` |
| Service Junction logic | `pressure_line.gd`, `drop_arm.gd`, `sentry_brain.gd` (pure logic); `sentry.gd` (its body); `hazard.gd` (hurtboxes) |
| Doors | `door_kit.gd` (every door's pieces, lamps, door lights and exit signs), `door_leaf.gd`, `seal_leaf.gd`, `blast_leaf.gd`, `swing_leaf.gd`, `slide_leaf.gd`, `bypass_handle.gd`, `world/door_camera.gd` |
| Effects | `impact.gd` (shake, hit-stop, flash), `fx_presets.gd` (particles), `fx/fx_kit.gd`, `fx/palette.gd`, `fx/tri_mesh.gd`, `fx/tweens.gd`, `floor_reflection.gd`, `wolf_lights.gd` |
| Sound | `sfx_bank.gd`: sounds generated in code, plus a few processed recordings |
| Text and input | `dialogue_boxes.gd`, `text_size.gd`, `hold_use.gd` (held interact), `i18n.gd` |
| Menus | `game_settings.gd` (Settings), `pause_overlay.gd`, `ui_motion.gd`, `studio_logo.gd` |
| Debug tools | `debug/`: see [Debug tools](/docs/development/debug-tools/#where-the-code-lives) |

- **Pure logic** scripts (`RefCounted`) hold rules with no drawing, so the suites can test them directly.
- **One home per number:** shared colours are in `fx/palette.gd`; the door camera is in `world/door_camera.gd`.

### Tests

- **One suite per file:** `apps/game/tests/*_test.gd`, each run as `godot --headless --script`.
- **Shared kit:** `tests/support/game_suite.gd` holds the bookkeeping every suite uses. Use it; don't copy it.
- **How to run them:** [Testing and CI](/docs/development/testing/#game-checks).

## The website

| Path in `apps/docs/` | What it holds |
| --- | --- |
| `content/docs/` | Every guide page, as MDX |
| `app/page.tsx` | The landing page |
| `app/docs/` | The guide layout and its components |
| `lib/` | Page source, SEO and structured data, the version reader |
| `mdx-components.tsx` | Components pages can use |

- **Styling:** Tailwind CSS tokens and utilities, and Fumadocs components. No new bespoke CSS.
- **Build:** a static export for GitHub Pages, deployed from `main`.
- **The version** shown on the site is read from `apps/game/project.godot` by `lib/version.ts`.
- **For AI assistants:** `llms.txt`, `llms-full.txt` and a Markdown copy of each page are built from the same pages.
