**What this page is for:** what has actually been checked, how, and what has not.

<Callout type="warn" title="No complete route has been played by hand">
  Most of the game has been checked only by headless test suites and rendered still frames. How it feels, how its timing reads and how it sounds are unproven until a hands-on playtest.
</Callout>

## Kinds of check

| Kind | What it is | What it proves |
| --- | --- | --- |
| Headless | Godot runs the game's code with no window | The logic and rules work |
| Rendered stills | Frames drawn in the [render container](/docs/development/setup/#rendered-captures) and looked at | How a moment looks in one frame |
| Hands-on play | A person plays the route in a game window | How it feels, reads and sounds |
| Export | A build is made and its package checked | The build was made and holds the right files |
| Device | The build runs on a real phone, PC or controller | It works on that hardware |

- **Never say something feels or reads well** unless it was played or read on a screen. See [Project rules](/docs/development/rules/).

<Details>
<Summary>Full record</Summary>

The language suite (`i18n_test`, October 16, 2026) checks the groundwork for translations. Only English is offered yet, and nothing on screen changes. It requires the suite to start in English (the `--language en` flag every suite starts with), the language table `apps/game/i18n/languages.json` to hold the twelve planned language files, each with a picker name, a review state, a fallback font, a reading speed and a row limit, and nothing to be offered whose fonts are not in the build. It resolves 39 locales through the game's own table (Mexico, Argentina and the US to Latin-American Spanish, Spain to Spain's file, Portugal to Brazilian Portuguese, Taiwan, Hong Kong and Macao to Traditional Chinese, and Ukraine never to Russian) and reads the saved language. Each language's picker name and machine-translation tag must be drawable by the game's fonts with only that language's own fallback behind them, and a Chinese character planted in a German catalog must fail that check. With made-up Simplified and Traditional Chinese catalogs, and Latin-American and Spain Spanish ones, a line only one file of a pair has must show English in the other, and the same lookup with every catalog left registered must show the other file's text, so the check can fail. It also requires the offered languages other than English, the translation files in `apps/game/i18n/` and the catalogs `project.godot` registers to be the same set, so no language is offered without its file and no file ships unoffered (a planted German file fails it). The overflow check the later language work uses is tried on planted labels and buttons, one for each case the research prototype missed (text inside a container, text cut short with an ellipsis or clipped, and text that grows too tall or off the bottom of the screen), each beside a twin that fits, and on the English title, where it must find nothing. All 25 suites also passed with the computer's language set to Spanish. These are headless checks: no translation exists yet, and none of this has been seen on screen.

The language setting (October 19, 2026) adds checks to three suites. `settings_test` requires the **GENERAL** tab to stay hidden while English is the only language, and saving other settings to write no language. A game started with Spanish saved starts in Spanish; once Spanish is no longer offered it starts in English and keeps the saved pick. `i18n_test` requires the list's own font chain to draw every planned language's name and tag in every language, without the game fonts' language fallback and without making rows taller.
