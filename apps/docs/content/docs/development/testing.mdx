**What this page is for:** how to check the source project and the website.

1. From the repository root, run `scripts/check-game.sh` to check the Godot project without opening a window.
2. Run `bun run docs:check` to check the website types.
3. Run `bun run docs:test` for the website tests.
4. Run `bun run docs:build` to export the static site and check its pages and links.

The [changelog](/docs/changelog/) records evidence from earlier versions. A headless check verifies project behavior. Timing, controls and game feel require hands-on play of a playable build.
