## Current availability

There is **no packaged game download, installer, store release, or release date yet**. The platform options on the [landing page](/#downloads) are planned distribution channels; none has a playable package today.

If you want to try the current prototype, you can download its source from GitHub and run it with Godot. This is a development snapshot, not a finished or supported release.

## Try the source build

1. Install [Godot 4.7.2](https://godotengine.org/download/archive/).
2. Download and extract the source ZIP above, or [clone the repository](https://github.com/MrDemonWolf/wolf-override).
3. In Godot Project Manager, choose **Import**, then select `apps/game/project.godot` inside the extracted folder.
4. Open the imported project and press **F5** to run it.

The playable slice covers a maintenance corridor and Records Access. Characters and some environments use provisional art. The [controls guide](/docs/controls/input/) explains keyboard, controller, and touch input. The [optional walkthrough](/docs/walkthrough/) contains puzzle solutions.

## What the source download includes

The ZIP contains the repository source, project files, and provisional assets. It does not contain an installer or mobile app package. The code and documentation use GPL-3.0-or-later; artwork has separate rights status. Read [credits and asset sources](/docs/credits/) and [legal and licensing notes](/docs/legal/) before reusing any material.

When a packaged release becomes available, this page and the [changelog](/docs/changelog/) will identify its version and supported platforms. Until then, the [development status](/docs/development/status/) explains what is playable and what remains in progress.
