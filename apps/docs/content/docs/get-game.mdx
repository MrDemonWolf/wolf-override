## Run the source game

1. Install the standard build of [Godot 4.7.2](https://godotengine.org/download/archive/) for your system.
2. Download the [source ZIP](https://github.com/MrDemonWolf/wolf-override/archive/refs/heads/main.zip) and extract it.
3. Open Godot. In the Project Manager, choose **Import**.
4. Select `apps/game/project.godot` inside the extracted folder.
5. Open the imported project.
6. Press **F5** to run the game.

- **Use exactly 4.7.2.** The project is pinned to that Godot version.
- **Your saves** go to the folder listed on [Saving and retrying](/docs/controls/saves/#where-saves-live).

<Details>
<Summary>Use Git and the command line instead</Summary>

1. Clone the repository:

   ```sh
   git clone https://github.com/MrDemonWolf/wolf-override.git
   cd wolf-override
   ```

2. Import the project once (this opens the Godot editor):

   ```sh
   godot --path apps/game --editor
   ```

3. After that, start the game directly:

   ```sh
   godot --path apps/game
   ```

- **Developers:** [Set up the project](/docs/development/setup/) covers Bun, the checks and the website.

</Details>

## What you can play

- **Current route:** a maintenance corridor, Records Access, the Service Junction and a maintenance annex.
- **Provisional art and sound.** Nothing is final.
- **Not played by hand yet:** no complete route has been played through by hand, so how it feels is unproven.
- **Next steps:** [First steps](/docs/controls/first-steps/), then [Controls](/docs/controls/input/).
- **Stuck?** The [walkthrough](/docs/walkthrough/) has puzzle solutions (spoilers).

## What the source download includes

- **Included:** the repository source, project files and provisional assets.
- **Not included:** an installer or a phone or tablet app.
- **Code licence:** GPL-3.0-or-later for code and documentation.
- **Art is different:** artwork has its own rights status. Read [Legal](/docs/legal/) and [Credits](/docs/credits/) before you reuse anything.
