## Try the source build

1. Install [Godot 4.7.2](https://godotengine.org/download/archive/).
2. Download and extract the source ZIP above, or [clone the repository](https://github.com/MrDemonWolf/wolf-override).
3. In Godot Project Manager, choose **Import**, then select `apps/game/project.godot` inside the extracted folder.
4. Open the imported project and press **F5** to run it.

The playable slice covers a maintenance corridor, Records Access and the Service Junction with provisional art. [Input](/docs/controls/input/) lists keyboard, controller, and touch controls, and the optional [chapter walkthrough](/docs/walkthrough/) contains puzzle solutions.

## What the source download includes

The ZIP contains the repository source, project files, and provisional assets, not an installer or mobile app package. The code and documentation use GPL-3.0-or-later; artwork has separate rights status. Read [Credits and references](/docs/credits/) and [Legal and licensing](/docs/legal/) before reusing any material.

When a packaged release becomes available, this page and the [changelog](/docs/changelog/) will identify its version and supported platforms. Until then, [Current status](/docs/development/status/) explains what is playable and what remains in progress.
