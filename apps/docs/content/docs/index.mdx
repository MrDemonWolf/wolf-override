WOLF//OVERRIDE is in its first playable prototype stage. M0 is one staged side-view corridor with two code-drawn characters, a door puzzle with cooperative and fallback routes, one remembered choice, and a safe point. There is no downloadable release yet.

For the spoiler-safe premise and gameplay direction, see [About the game](/docs/about/). [Development status](/docs/development/) separates the current source build from future plans.

## Open the game

Install Godot **4.7.2 stable**, then run from the repository root:

```sh
godot --path apps/game --editor
```

Press **F5** in the editor to run the project, or use the **Run Project** button. To start the game directly:

```sh
godot --path apps/game
```

## Controls

| Key | Action |
| --- | --- |
| A / D or arrow keys | Move the active character |
| E | Interact with a nearby station |
| Tab | Switch characters in the amber floor zone |
| 1 / 2 | Answer the corridor disagreement |
| I | Cycle provisional engineer display names |
| L or F9 | Load the saved checkpoint |
| N | Start a clean New Game |

The far-right safe point saves when you interact with it. WOLF can refuse the relay; the engineer has a fallback route. The opening corridor sets up WOLF's self-awakening and the Director's attempt to erase records.

Corridor play currently requires a keyboard. Touch controls and mobile exports have not been implemented.

## Check the source

These commands check import, state logic, both door routes, and checkpoint save/load through the scene. They do not prove graphical play or exported builds.

```sh
godot --headless --path apps/game --import
godot --headless --path apps/game --script res://tests/m0_state_test.gd
godot --headless --path apps/game --script res://tests/m0_scene_test.gd
```

The current title and opening corridor were inspected graphically in Godot 4.7.2. Both full routes, Continue, and save/load still need graphical playtesting. Finished character/environment art, audio, export packages, and device tests are future work.
