## Start playing

<Callout title="No installer yet">
  There is no packaged installer or public release yet. The source archive is a development snapshot, not a ready-to-run app.
</Callout>

1. [Get the game](/docs/get-game/): an unsigned test build for macOS or Windows, or the source game in **Godot 4.7.2**.
2. Start it and choose **New Game**.
3. Follow the spoiler-light [First steps](/docs/controls/first-steps/) for movement, interaction prompts, choices and checkpoints.

- **Keys, buttons and touch:** [Controls](/docs/controls/input/).
- **Saving:** [Saving and retrying](/docs/controls/saves/) explains Continue, Return to Title, New Game and where the single checkpoint file lives.

## Your first goal

- **Goal:** restore power and open the sealed maintenance door.
- Read the station labels and the nearby interaction prompt.
- Objective cards appear briefly when your goal changes.
- WOLF can help or refuse. You keep control of the engineer, and a manual route lets you continue if he declines.
- A choice you make in the corridor is remembered later.
- **Stuck?** The [optional chapter walkthrough](/docs/walkthrough/) separates each room's steps, including the annex. It reveals only the current source chapter.

## What to expect

- Characters and environments use provisional artwork.
- Final animation, sound, the wider campaign, and release packages are still in development.
- The current chapter is a small beginning, and its puzzles do not select a campaign ending.
- [What was checked](/docs/development/evidence/) lists what has actually been checked, including that complete routes have not been played by hand.
