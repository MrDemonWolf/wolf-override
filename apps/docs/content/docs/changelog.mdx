These are development updates to the source build, not downloadable releases. There is no public game package or automatic updater yet. Original concept, core story and creative vision: Nathanial Henniges.

## October 8, 2026

- After you tell WOLF about the relay risk, he walks to the contact himself; you no longer have to find the exact spot. Using the relay again while he is walking takes the engineer's bypass instead.
- Removed the N (new run) and L/F9 (load checkpoint) hotkeys, which discarded unsaved progress without warning. Use Pause, then Return to Title, then New Game or Continue.
- Pause during the opening now pauses instead of skipping; choose **Skip Opening** from Pause to go straight to play.
- On Android, Back backs out of menus and pauses play instead of closing the game; it only closes the game from the title screen.
- Switching away from the game during play pauses it.
- Returning to the title no longer leaves an unanswered choice that a later key press could answer.
- In-game changelog and credits links point at wolfoverride.mrdemonwolf.dev.
- Settings files are now read safely: damaged, oversized or unexpected content is ignored and default settings load instead.
- When Continue is unavailable, a note under it says whether no checkpoint exists yet or the saved checkpoint could not be read.
- When entering Records Access, copying a trace or securing the exit fails to save, the hint line now says so instead of a character's dialogue, and tells you to use a station to try again; normal hints return once you move on or a later save works.
- If the checkpoint file is missing or damaged, Continue uses a complete save that was still being written when the game closed, and Continue keeps working with saves made before small wording changes.
- Continuing in Records Access now tells you which copy is next or that the exit is open.
- Title, credits and Pause menus now use the same cyan selection outline as Settings, drawn inside each button, and Settings sliders now use it too; Pause menu buttons and the Settings **BACK**, FPS limit and resolution controls also thicken and fill so the selection stands out from their border.
- Menus opened by touch no longer show a selection outline; the first arrow key or controller press selects a menu item without activating it. With a keyboard or controller, closing title Settings by **BACK**, Esc, controller B or Android Back returns the selection to **SETTINGS**; after closing it by touch, the first arrow key or controller press selects **SETTINGS**.
- The opening tutorial now matches the objective card: it marks the nearby display as optional, points toward your first goal instead of sending you back, clears when you reach that goal or interact with anything, and sits clear of the display and station art.
- Website: the Roboto and Montserrat fonts now load as small Latin-subset WOFF2 files (about 73 KB together instead of 1.2 MB of TTF).
- Website: the landing key art and the guide screenshots are now WebP files sized for the screen (the key art drops from 1.5 MB to under 80 KB at full size), the gameplay screenshots are fresh October 8 captures of the source build, and the first-steps tutorial shows the title screen again.
- Website: the landing page's download section is now a single **Get the build** section with one **Get the source build** action and a plain list of planned platforms (Windows, macOS, iPhone/iPad, Android), each marked "no release date". The platform picker, the six disabled "Coming soon" buttons and the hover-only hints are gone; the navigation and footer link to it as **Get the build**. There is still no packaged download.
- Website: the landing page is dark only and no longer has its own theme toggle; the game guide keeps its light/dark setting. Landing labels use Montserrat instead of a typewriter face, every landing link and button is at least 16 px, and button and card borders use a stronger line that measures at least 3:1 against their background.
- Website: the **The relationship is the game** and **Follow the build** section labels on the landing page now get the same Montserrat label treatment as the other section labels (a page stylesheet rule had been overriding them), and the small captions inside the two progress cards ("Development updates", "For source players & contributors") are now 16 px like the rest of the card text.

## October 7, 2026

- Esc and controller Start now resume from Pause; previously they could reopen Pause on the same press.
- Esc or controller B in in-game Settings returns to the Pause menu instead of resuming; closing Settings from the title returns focus to the title menu.
- Esc cancels a key rebind without leaving Settings.
- Game and website now use the Roboto and Montserrat typefaces (SIL Open Font License 1.1).
- Corridor and Records Access backgrounds keep their 16:9 framing, and the provisional Director and WOLF sprites were re-exported.
- Website: a mobile navigation menu that opens over the page, a restyled landing page, readable hover states on the main buttons, and underlined links in the guide again.

## September 30, 2026

### Menus and controls

- Restyled Settings with a terminal theme, clearer section labels and square-edged controls. The title screen keeps its game presentation.
- Added a closer, smooth horizontal gameplay camera that follows the engineer while keeping the room edges inside view.
- Added **Return to Title** to Pause for keyboard, controller and touch checkpoint recovery. Returning keeps the last checkpoint; unsaved progress is lost.
- Fixed controller confirmation and remapped response conflicts so the intended choice is remembered.
- Improved settings tab spacing, typography, padding, focus indicators and dropdown styling.
- Hardened saved preferences against invalid values and conflicting bindings.
- Fixed interrupted-load transitions and allowed Pause during closing dialogue.

### Scene presentation

- Added a framed containment cage, a gate that slides aside, and WOLF stepping forward after it opens.
- Moved cinematic prompts and response cards clear of characters; adjusted the closing camera to show both actors above dialogue.
- Corrected nearby checkpoint prompts and callbacks to match the route actually taken.
- Expanded in-game and website credits with consulted design research, separate from project contributors.

### Website and development

- Reorganized the guide into a short start page, controls/settings and optional chapter walkthrough. Updated setup links and save behavior, kept private campaign drafts out, and clarified code versus asset licensing.
- Fixed Skip to content to move keyboard focus to the page heading, with a visible focus outline.
- Added page-specific search and social-sharing metadata, canonical URLs, author credits and an automatically generated sitemap for the public website and guide.
- Updated the public corridor screenshot for the closer camera, labeled as a development capture. Removed the terminal title-menu promotion from the landing page.
- Refined the landing page after official game-site research: clearer player actions, a labeled source-game frame, a shorter mobile hero and selected-platform downloads with other channels in a disclosure. Unavailable buttons no longer imitate active external links; guide and changelog links stay usable.
- Redesigned the marketing homepage with cinematic key art, story and gameplay sections, and platform suggestions. All six planned download/store channels remain unavailable with visible Coming soon labels and browser tooltips.
- Added this changelog and a title-screen link that opens it in your browser.
- Added manual CI runs, bounded job times and downloadable game-check failure logs.
- Recorded a staged Sparkle plan for direct macOS distribution. Integration is **not implemented or enabled**.

Five deterministic Godot checks and the docs build passed during the UI review. Agents inspected 44 rendered stills. This does not replace complete hands-on routes, physical-controller testing, touch-device testing or export checks.

## Earlier foundation

The initial source slice established engineer-only movement, WOLF's independent cooperation/refusal, a manual puzzle fallback, remembered choices, checkpoints and save/load across two rooms. The public site added a play guide, development setup, light/dark themes and credits.

## What is next

Complete hands-on route testing comes first. Directional character animation, sound, adjustable dialogue presentation and release/device validation remain future work. Story drafts stay private; this page records source changes without campaign spoilers.
