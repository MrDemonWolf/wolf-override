**What this page is for:** what changed in each development version, newest first. Spoiler-free.

<CurrentVersion />

- **Versions** are numbered `0.MINOR.0`, one per milestone (a day of finished work). They are development versions of the source build, not downloadable releases.
- **No release yet.** There is no public release or automatic updater. The automatic test builds are unsigned debug builds for testing, kept for 14 days.
- **Read the short lines.** Each version lists one-line changes by group. Open **Full notes** under a version for every detail.
- **How it was checked** closes each version. "Not played by hand" means only automated tests and still images saw it.
- **Credit:** original concept, core story and creative vision: Nathanial Henniges.
