These are development updates to the source build, not downloadable releases. There is no public game package or automatic updater yet. Original concept, core story and creative vision: Nathanial Henniges.

## September 30, 2026

### Menus and controls

- Restyled Settings with a terminal theme, clearer section labels and square-edged controls. The title screen keeps its game presentation.
- Added a closer, smooth horizontal gameplay camera that follows the engineer while keeping the room edges inside view.
- Added **Return to Title** to Pause for keyboard, controller and touch checkpoint recovery. Returning keeps the last checkpoint; unsaved progress is lost.
- Fixed controller confirmation and remapped response conflicts so the intended choice is remembered.
- Improved settings tab spacing, typography, padding, focus indicators and dropdown styling.
- Hardened saved preferences against invalid values and conflicting bindings.
- Fixed interrupted-load transitions and allowed Pause during closing dialogue.

### Scene presentation

- Added a framed containment cage, a gate that slides aside, and WOLF stepping forward after it opens.
- Moved cinematic prompts and response cards clear of characters; adjusted the closing camera to show both actors above dialogue.
- Corrected nearby checkpoint prompts and callbacks to match the route actually taken.
- Expanded in-game and website credits with consulted design research, separate from project contributors.

### Website and development

- Added page-specific search and social-sharing metadata, canonical URLs, author credits and an automatically generated sitemap for the public website and guide.
- Updated the public corridor screenshot for the closer camera, labeled as a development capture. Removed the terminal title-menu promotion from the landing page.
- Refined the landing page after official game-site research: clearer player actions, a labeled source-game frame, a shorter mobile hero and selected-platform downloads with other channels in a disclosure. Unavailable buttons no longer imitate active external links; guide and changelog links stay usable.
- Redesigned the marketing homepage with cinematic key art, story and gameplay sections, and platform suggestions. All six planned download/store channels remain unavailable with visible Coming soon labels and browser tooltips.
- Added this changelog and a title-screen link that opens it in your browser.
- Added manual CI runs, bounded job times and downloadable game-check failure logs.
- Recorded a staged Sparkle plan for direct macOS distribution. Integration is **not implemented or enabled**.

Five deterministic Godot checks and the docs build passed during the UI review. Agents inspected 44 rendered stills. This does not replace complete hands-on routes, physical-controller testing, touch-device testing or export checks.

## September 29, 2026

- Added a player-paced Director/WOLF opening before the engineer enters gameplay.
- Added short-lived location and objective cards, a guided movement/interaction tutorial, and clearer station feedback.
- Improved speaker labels, response cards and the chapter closing beat.
- Added controller and touch input, Pause, and saved Display, Audio and Controls settings.
- Added provisional room and machinery artwork with provenance in the asset register.

## Earlier foundation

The initial source slice established engineer-only movement, WOLF's independent cooperation/refusal, a manual puzzle fallback, remembered choices, checkpoints and save/load across two rooms. The public site added a play guide, development setup, light/dark themes and credits.

## What is next

Complete hands-on route testing comes first. Directional character animation, sound, adjustable dialogue presentation and release/device validation remain future work. Story drafts stay private; this page records source changes without campaign spoilers.
