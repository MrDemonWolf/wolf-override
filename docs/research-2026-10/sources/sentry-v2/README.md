# Purge sentry, version 2 (October 9, 2026)

The junction's purge sentry, redrawn so its top no longer reads as a gun: in the game it patrols, chases and knocks the engineer down on contact, but never fires.

## Decision

**October 9, 2026:** on the Service Junction art review ([`../../notes/review-pages/2026-10-09-junction-art.md`](../../notes/review-pages/2026-10-09-junction-art.md), Check 4) Nathanial Henniges chose "Redo as scanner (Recommended)". Version 2 keeps the approved body and replaces the long cyan emitter with a scanner head (`APPROVED`). The Look 2 redo of the same design is in [`../look2-hq/sentry/`](../look2-hq/sentry/).
