# Notes index

Since 2026-10-16 the project's design notes, research write-ups, reviews and plans live in Notion, which is their source of truth. They are private (they hold story spoilers), so the links below open only for project members. Write new notes there through Codex, not here.

The repository keeps the rules and records that agents and builds need: `AGENTS.md`, `AGENT.md`, `PRIVATE_AGENTS.md`, `PROJECT_CONTEXT.md`, `docs/decisions.md`, `docs/next-session.md`, `docs/exports.md`, `docs/legal-release.md`, `docs/sources.md`, the two `SOURCES.md` source lists under `docs/research-2026-10/`, the approved wording in `docs/research-2026-10/approved/` (read by the game's tests), the asset register (`apps/game/assets/manifest.json`) and the public credits page.

Every moved file is still in git history at commit `1cf8d73`: open one with `git show 1cf8d73:<path>` or on GitHub at `https://github.com/MrDemonWolf/wolf-override/tree/1cf8d73c4703f8d8dfb693c41fc57c62c43118e3/docs`. Comments in code and the asset register write such paths as `1cf8d73:docs/...` or as those GitHub links. Images, prompts, logs and research tools were not copied into Notion; each Notion page links them at that commit, and every source, tool and model credit moved with its note.
