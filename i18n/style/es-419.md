# Español (Latinoamérica): style guide

File `es.po`, glossary key `es-419`. Neutral Latin-American Spanish that reads naturally in Mexico. Read
[the shared guide](README.md) first.

## Address and register

- **tú** between characters and in hints, never usted or vos.
- Buttons and objectives in the infinitive (NUEVA PARTIDA is a noun phrase and fine; CONTINUAR, SALIR).
- Personal **a** before the name as an object ("vio a %s").

## The engineer

Adjectives and participles agree in Spanish (solo/sola, listo/lista), and job nouns do too
(ingeniero/ingeniera, técnico/técnica). So:
- Use an adverbial phrase instead of an agreeing adjective: "sin ayuda", "por su cuenta", "a la vista"
  (not "sola", "expuesta").
- Name the department, not the person: the name card reads INGENIERÍA DE MANTENIMIENTO.
- Watch the passive and "estar" + participle about the engineer ("está atrapado/atrapada"): rephrase
  with an active verb or a noun.
- No "elle" or "-e" endings unless Nathanial chooses them.

## WOLF

WOLF is **él**, with masculine agreement ("WOLF está listo"). He uses tú. Calm and dry; no ¡…! in his
lines.

## Names

The three names stay as written (Rowan, Alex, Morgan). Possessives use "de %s".

## Quotes and punctuation

- Quotes «…».
- Opening ¿ and ¡ where the sentence needs them, though WOLF does not exclaim.
- Plates in capitals keep their accents (RELÉ, not RELE).

## Open questions

- **breaker**: not "interruptor", which reads back as "switch" (both of the trial's Spanish drift
  flags). A reviewer picks "disyuntor" or the loanword "breaker" (D11). PR L9 uses DISYUNTOR, which
  Codex read back as "circuit breaker".
- **LOCKDOWN**: not BLOQUEO, which reads back as "blockage". "CIERRE DE EMERGENCIA" is a proposal; it is
  long for the title's chapter line, so PR L9 uses CIERRE TOTAL there (read back as "total lockdown").
- **SERVICE JUNCTION**: a reviewer's word.
- **Words cut to fit (PR L9)**: NEW GAME is EMPEZAR, VALVE USED is VÁLV. USADA and TEXT SIZE is TEXTO,
  because the longer words overflow their button, run into the next plate (i18n_test) or run under the
  list beside them (the Settings still). NUEVA PARTIDA (213 px on a 186 px button) can return once PR L8
  widens the title's buttons.
