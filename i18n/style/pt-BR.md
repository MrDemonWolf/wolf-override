# Português (Brasil): style guide

File `pt_BR.po`, glossary key `pt-BR`. Brazilian Portuguese; players in Portugal read this file too.
Read [the shared guide](README.md) first.

## Address and register

- **você** between characters and in hints (the everyday Brazilian form), never o senhor.
- Buttons and objectives in the infinitive (CONTINUAR, SAIR).

## The engineer

Adjectives and participles agree (sozinho/sozinha, pronto/pronta, morto/morta), and job nouns do too
(engenheiro/engenheira). So:
- Use an adverbial phrase: "sem ajuda", "por conta própria", "à vista".
- Name the department: ENGENHARIA DE MANUTENÇÃO.
- Rephrase "está + participle" about the engineer with an active verb or a noun.
- No neopronoun (elu) unless Nathanial chooses it.

## WOLF

WOLF is **ele**, with masculine agreement. Informal and dry; no exclamation marks.

## Names

As written; possessives with "de %s".

## Quotes and punctuation

Quotes “…”. Plates in capitals keep their accents.

## Open questions

- **coolant**: "refrigerante" means a soft drink in Brazil, so the glossary proposes "líquido de
  arrefecimento" (required: "arrefecimento").
- **LOCKDOWN**: "CONFINAMENTO" is a proposal; whether BLOQUEIO reads as "blockage" here, as in Spanish,
  is for a reviewer.
- **SERVICE JUNCTION**: a reviewer's word.
