M10 Settings, phone and tablet

What this page is for: judge the full-screen settings on a phone and a tablet, touch first.

The six states above

  1. CONTROLS on touch: TOUCH SCHEME, CONTROL SIZE, SWAP SIDES and HAPTICS.
  2. DISPLAY: phone rows only. FRAME RATE is open: 30, 60 or 120 FPS.
  3. ACCESSIBILITY: too many rows for one screen, so the page scrolls. Text never shrinks.
  4. CONTROLS with a pad connected: controller rows come first, then the touch rows.
  5. AUDIO: one slider per sound.
  6. GENERAL: DEVICE PROFILE fixes a wrong guess in one change. RESET is hold to confirm.

Layout (proposal)

  • The tabs stand in a column on the left. A phone is short, so a tab row would cost a row of settings.
  • BACK sits top right, in the title row. That leaves room for five or six rows.
  • Rows stay 44 pt tall or more. Long pages scroll; the last row fades when more lies below.
  • On the iPad every page fits, so nothing scrolls there.

Not on a phone

  • WINDOW MODE, WINDOW SIZE, MONITOR and V-SYNC: the OS owns the window.
  • MUTE WHEN UNFOCUSED and PAUSE WHEN UNFOCUSED: a phone always pauses and mutes.
  • CLICK / TAP TO INTERACT: TOUCH SCHEME covers it.
  • QUIT: never on iOS. Android Back quits from the bare title.

How to use it

  • Set Device to iPhone, Android or iPad in the strip.
  • Set Phone controls to "tap to walk" to see the other TOUCH SCHEME.
  • Set Input to pad to see every state with pad prompts and the focus ring.
  • Android: add cutout= and edge= (canvas px) to see the unmeasured bands.
