M08 Settings, desktop

What this page is for: check the desktop Settings screen in a 1280 × 720 Mac window, mouse first, then keyboard and pad.

  • Every frame is the same screen in a different state. Each one holds all five tabs.
  • Frames are always the 1280 × 720 Mac window. The strip's Device does not change them; M09 and M10 show the other devices.
  • Pick mouse, keyboard or pad in the strip. Glyphs and the focus ring follow it.
  • Click a tab, or press LB or RB on a pad, to switch tabs.
  • Arrow keys or the D-pad walk the rows of the frame in focus.
  • Click a row, a switch or a list. Lists open under their row, or above it near the bottom.
  • The Speaker switch in the strip shows the name tab or a placeholder portrait crop in the preview.
  • Values are written in caps, as on M09 and M10. The build writes some in sentence case ("Off"); the shared settings data file should pick one.

Built in the shared step (November 11): an open list floats over the scrolling page; the five tabs fit (H3); the D-pad walk skips the tabs and wraps; LB and RB move focus to the new page; the row is the one focus mark; switches grow with TEXT SIZE and say ON or OFF; HOLD's fill is darker; footer prompts are clickable.

Still open: the keep-or-undo countdown puts WINDOW SIZE back only when its dialog names the old size (data-wo-revert), and the rows are still written by hand until the shared 3.2 settings file exists.

States: DISPLAY · fullscreen and the FRAME LIMIT list · keep or undo · AUDIO · rebind a key · rebind a pad button · hold to restore · ACCESSIBILITY · dialogue preview · GENERAL

1. DISPLAY

  • The 760 × 464 terminal card over the dimmed title art (3.1 step 5).
  • One column: label left, control right. Every control starts at the same x.
  • WINDOW SIZE has focus. A mouse shows no ring. A key or pad press shows it.
  • Windows shows WINDOW MODE where macOS shows FULLSCREEN.
  • MONITOR shows only with two or more screens.

2. Fullscreen, and the FRAME LIMIT list with V-sync on

  • FULLSCREEN is on, so WINDOW SIZE is greyed and says why (proposal copy).
  • The FRAME LIMIT list is open under its row. Near the bottom it opens above instead.
  • The list floats over the page's scroll box, as Godot shows it whole. If it fits neither below nor above, it slides into the safe area.
  • With V-sync on at 60 Hz, 60 FPS and up are greyed (3.2: at or above the refresh rate).
  • The note says why 60 FPS is greyed (proposal copy; 3.2's note was "V-sync on: up to 60 Hz").
  • The footer stays in place.

3. Keep or undo a window change

  • WINDOW SIZE just changed to 1600 × 900. Only WINDOW SIZE, and WINDOW MODE on Windows, ask.
  • The count runs live from timing.keep-revert. At 0 the dialog closes by itself. Reload to see it again.
  • KEEP has focus. A, Enter or a click keeps. B, Esc, UNDO or a click on the footer's UNDO undo.
  • The dialog's words are proposal copy.

4. AUDIO

  • Five sliders, 0 to 100, default 100. One press moves one step.
  • MASTER has focus. The note is the build's.

5. CONTROLS: rebinding a key

  • Keyboard first on the desktop. CONTROLLER follows on the same page; scroll down.
  • INTERACT / CONTINUE waits for a key. It pulses slowly; REDUCED MOTION holds it steady.
  • The note under it is the build's.
  • CANCEL REBIND takes BACK's place. Its glyph follows the input. A mouse user clicks it.

6. CONTROLS: rebinding a pad button

  • The page scrolled to CONTROLLER. Each binding shows its Xbox glyphs, not words.
  • INTERACT / CONTINUE waits for a pad input. A and B would be captured, so Menu cancels (4.6).
  • The note's first sentence is the build's. "[Menu] cancels." is the 4.6 proposal; the build says "Esc cancels."

7. CONTROLS: hold to restore the defaults

  • The end of the page. RESTORE DEFAULT CONTROLS is held, 60% of the way.
  • A hold, not a second dialog (Celeste 1.4). It fills over timing.hold-confirm.
  • Hold the click, Enter or pad A on it to try it. Letting go early empties it.
  • A mouse sees HOLD only; a key or pad player sees its glyph too.

8. ACCESSIBILITY

  • TEXT SIZE and REDUCED MOTION moved here from DISPLAY.
  • The rows keep the same control column as every other page.
  • The live preview sits under the dialogue rows. Scroll down, or see state 9.
  • TEXT SIZE in the strip changes the whole screen. The row's value does not follow it yet.

9. ACCESSIBILITY: the dialogue preview

  • The page scrolled to its end. DIALOGUE BACKING has focus.
  • The preview is the real dialogue box over the corridor plates, M10's one copy.
  • It follows TEXT SIZE (strip), dialogue.backing (Tune) and the Speaker switch (strip).
  • The portrait is a placeholder crop of the stand sprite; no portrait art exists.
  • The WOLF mark (his eye) waits on the speaker-mark decision.

10. GENERAL

  • LANGUAGE names each language in itself. Its note is the build's.
  • DEVICE PROFILE says what Auto picked. Its note is proposal copy.
  • RESET ALL SETTINGS is a hold, like RESTORE DEFAULT CONTROLS.
