M08 Settings, desktop

What this page is for: check the desktop Settings screen in a 1280 × 720 Mac window, mouse first, then keyboard and pad.

  • Each frame below is one state. Scroll down through them.
  • Pick mouse, keyboard or pad in the strip. Glyphs and the focus ring follow it.
  • Arrow keys walk the focused frame. The walk wraps at the end.
  • Tabs, lists, the countdown and the hold do not move yet. Each state is its own frame.
  • Rows are 35 or 40 canvas px, not 32, until the shared row fix lands.

States: DISPLAY · fullscreen and FRAME LIMIT list · keep or undo · AUDIO · CONTROLS keyboard rebind · CONTROLS controller · CONTROLS hold to restore · ACCESSIBILITY · ACCESSIBILITY dialogue preview · GENERAL

1 · DISPLAY

  • Mouse first. Six rows in one column: label left, value right.
  • WINDOW SIZE has focus. A mouse shows no ring; a key or pad press shows it.
  • Windows shows WINDOW MODE where macOS shows FULLSCREEN.
  • MONITOR shows only with two or more screens.
