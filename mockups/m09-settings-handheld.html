M09 Settings, ROG Ally (2023)

What this page is for: judge the full-screen settings on the ROG Ally (2023), Xbox pad first.

The six states above

  1. CONTROLS: controller bindings come first. Keyboard keys stay folded while a pad is used.
  2. Pad rebind: A and B would be captured, so Menu cancels. CANCEL REBIND stays tappable.
  3. DISPLAY: FRAME LIMIT is open. Choices 30, 40, 60, 120 and Match display. 120 is greyed while V-sync is on.
  4. AUDIO: one slider per bus, one step per D-pad press.
  5. ACCESSIBILITY: TEXT SIZE is 125%, the handheld default. A live dialogue preview sits beside the rows.
  6. GENERAL: DEVICE PROFILE fixes a wrong guess in one change. RESET is hold to confirm.

How to use it

  • Set Input to pad, then touch, in the strip. A tap shows touch prompts, never keyboard ones.
  • Every frame is the ROG Ally (2023): 1920 × 1080, rows 48 canvas px, TEXT SIZE 125%.
  • Speaker in the strip switches the preview between the name tab and the placeholder portrait.
